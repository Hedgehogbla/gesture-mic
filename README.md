# Gesture Mic

Выключение микрофона в Discord указательным пальцем перед вебкамерой.

```
указательный палец вверх  →  Discord mute/unmute
```

Работает локально: кадры никуда не отправляются. Распознавание — по 21 точке
кисти (MediaPipe Hand Landmarker), сами жесты — по углам сгиба пальцев.

## Как это работает

```
кадр 640×480
   │  cv2.cvtColor: BGR → RGB
   ▼
MediaPipe Hand Landmarker → 21 точка кисти (x, y, z)
   │  перевод в пиксели: (x*w, y*h, z*w)
   ▼
gestures.py: угол в суставе каждого пальца > 150° → палец выпрямлен
   │  выпрямлен только указательный → "point"
   ▼
stabilizer.py: жест держится 0.5 с и срабатывает один раз
   ▼
mute.py: нажатие Ctrl+Shift+M → Discord переключает свой мут
```

Модель — только «глаз»: она находит точки. Решение «это жест» и «что делать» —
обычный Python-код, который можно прочитать и изменить.

## Настройка Discord (один раз)

1. Discord → **Настройки пользователя → Keybinds** (в русском клиенте —
   «Комбинации клавиш»).
2. Найдите действие **Toggle Mute**.
3. Назначьте **Ctrl+Shift+M** — именно эту комбинацию нажимает программа.
4. Discord должен быть запущен, иначе нажимать некуда.

Комбинация задаётся в `config.json` → `mute.hotkey`. Если хотите другую —
поменяйте в обоих местах.

## Требования

- Windows 10/11
- Python 3.12 (MediaPipe не поддерживает 3.13+)
- Вебкамера
- Discord

## Установка

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Модель `models/hand_landmarker.task` скачается при первом запуске (7.8 МБ).
В git она не хранится.

## Запуск

```powershell
run.bat
```

Или:

```powershell
.venv\Scripts\python main.py
```

В VS Code: **F5** (конфигурация «Gesture Mic» уже лежит в `.vscode/launch.json`).

Выход: `Q` / `Esc` в окне превью или `Ctrl+C` в консоли.

Полезные флаги:

```powershell
.venv\Scripts\python main.py --camera 1        # другая камера
.venv\Scripts\python main.py --no-window       # без окна превью
.venv\Scripts\python main.py --duration 10     # остановиться через 10 секунд
```

## Тесты

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

18 тестов: правила жестов, стабилизатор и разбор хоткея. Камера и MediaPipe
для них не нужны — поэтому они выполняются за миллисекунды.

## Настройка

Всё в `config.json`:

| Ключ | Смысл |
|---|---|
| `camera.index` | Номер камеры (0 — встроенная) |
| `camera.mirror` | Зеркалить картинку |
| `gesture.hold_ms` | Сколько держать жест до срабатывания |
| `gesture.cooldown_ms` | Пауза между срабатываниями |
| `gesture.extended_angle` | Порог «палец разогнут», градусы |
| `mute.backend` | `discord_hotkey` или `windows_mic` |
| `mute.hotkey` | Комбинация, которую слушает Discord |
| `actions` | Какой жест какое действие вызывает |
| `feedback.beep` | Звук при срабатывании |
| `feedback.show_preview` | Показывать окно |

Действия: `mute`, `unmute`, `toggle`. Жесты: `point`, `closed_fist`, `open_palm`,
`victory`, `thumb`. Можно повесить несколько жестов на одно действие или
добавить второе действие, например:

```json
"actions": {
  "point": "toggle",
  "closed_fist": "mute"
}
```

### Два backend'а

| Backend | Что делает | Плюсы | Минусы |
|---|---|---|---|
| `discord_hotkey` | нажимает хоткей Discord | меняется именно мут Discord | состояние в превью — наша память, может разъехаться |
| `windows_mic` | глушит системный микрофон | состояние читается реально, работает во всех программах | в Discord иконка не меняется |

## Почему не через Discord API

У Discord нет публичного способа выключить микрофон **своего** клиента:

- Bot API умеет только серверный мут участника — нужен бот на сервере и права;
- локальный RPC для управления голосом устарел и не гарантируется;
- OAuth2 даёт доступ к аккаунту, но не к кнопке mute в клиенте.

Горячая клавиша — официальный механизм Discord, поэтому используется он.
Подробнее про API и почему это так: [docs/discord-api.md](docs/discord-api.md).

## Если что-то не работает

**Жест виден, но Discord не реагирует** — не задан хоткей в Discord, Discord
закрыт, или Discord запущен от администратора, а программа нет (Windows не
пропускает ввод в приложения с более высокими правами).

**«Не удалось открыть камеру»** — камера занята (Zoom, OBS, браузер) или
запрещена в «Параметры → Конфиденциальность → Камера».

**Жест срабатывает слишком легко** — увеличьте `gesture.hold_ms` до 700–900.

**Указательный палец не распознаётся** — снизьте `gesture.extended_angle`
до 140 и держите руку целиком в кадре, свет спереди.

**Состояние MIC в превью не совпадает с Discord** — это ожидаемо для
`discord_hotkey`: программа помнит только свои переключения. Перезапустите её
или переключитесь на `windows_mic`.

**Кириллица в пути** — MediaPipe на Windows не открывает такие пути, поэтому
модель автоматически копируется в `C:\Users\Public\GestureMic\models`.

## Структура

```
gesture-mic/
├─ main.py          цикл: камера → жест → действие
├─ gestures.py      точки → имя жеста (чистые функции)
├─ stabilizer.py    удержание и пауза между срабатываниями
├─ mute.py          backend'ы: Discord hotkey / Windows mic
├─ overlay.py       скелет кисти и HUD
├─ config.json      настройки
├─ tests/           unittest, без камеры
├─ models/          сюда скачивается модель (в git не попадает)
└─ docs/            заметки про Discord API
```

## Ограничения

- Одна рука в кадре.
- Только статические позы, без движений.
- Discord-хоткей не читает реальное состояние мута.
- Нет автозапуска и режима в трее.
