# Gesture Mic

Управление микрофоном Discord и Яндекс Музыкой жестами руки перед вебкамерой.

| Жест | Действие |
|---|---|
| ☝️ Указательный палец | Discord: mute / unmute |
| ✊ Кулак | Яндекс Музыка: play / pause |
| 👍 Большой палец вправо | Следующий трек |
| 👎 Большой палец влево | Предыдущий трек |

«Вправо/влево» — как в зеркале превью: поднял большой палец в свою правую
сторону — на экране он тоже справа.

Работает локально: кадры никуда не отправляются. Распознавание — по 21 точке
кисти (MediaPipe Hand Landmarker), жесты — по углам сгиба пальцев.

## Как это работает

```
кадр 640×480
   │  cv2.cvtColor: BGR → RGB
   ▼
MediaPipe Hand Landmarker → 21 точка кисти (x, y, z)
   │  перевод в пиксели: (x*w, y*h, z*w)
   ▼
gestures.py: угол в суставе каждого пальца > 150° → палец выпрямлен
   │  выпрямлен только указательный → "point"
   │  кулак → "closed_fist"
   │  кулак + большой палец вбок → "thumb_left" / "thumb_right"
   ▼
stabilizer.py: жест держится 0.5 с и срабатывает один раз
   ▼
actions.py: имя действия → реальный вызов
   ├─ mute.py  → Ctrl+Shift+M для Discord
   └─ media.py → медиа-клавиша Windows для Яндекс Музыки
```

Модель — только «глаз»: она находит точки. Решение «это жест» и «что делать» —
обычный Python-код, который можно прочитать и изменить.

## Медиа-клавиши и Яндекс Музыка

Для музыки не нужен API Яндекс Музыки: программа нажимает **глобальные
медиа-клавиши Windows** (`play/pause`, `next`, `prev`). Windows сама отдаёт их
активной медиа-сессии — это может быть приложение Яндекс Музыки или вкладка
браузера.

Что важно:

- музыка должна уже играть — тогда Windows считает сессию активной;
- если играют два плеера, клавиша уйдёт тому, который играл последним;
- клавиши работают, даже когда окно Яндекс Музыки свёрнуто.

## Настройка Discord (один раз)

1. Discord → **Настройки пользователя → Keybinds** («Комбинации клавиш»).
2. Действие **Toggle Mute** → назначить **Ctrl+Shift+M**.
3. Discord должен быть запущен.

Комбинация задаётся в `config.json` → `mute.hotkey`. Если меняете — поменяйте
в обоих местах.

## Требования

- Windows 10/11
- Python 3.12 (MediaPipe не поддерживает 3.13+)
- Вебкамера
- Discord и/или Яндекс Музыка

## Установка

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Модель `models/hand_landmarker.task` скачается при первом запуске (7.8 МБ).
В git она не хранится.

## Запуск

```powershell
run.bat
```

Или:

```powershell
.venv\Scripts\python main.py
```

В VS Code: **F5** (конфигурация «Gesture Mic» уже лежит в `.vscode/launch.json`).

Выход: `Q` / `Esc` в окне превью или `Ctrl+C` в консоли.

Полезные флаги:

```powershell
.venv\Scripts\python main.py --camera 1        # другая камера
.venv\Scripts\python main.py --no-window       # без окна превью
.venv\Scripts\python main.py --duration 10     # остановиться через 10 секунд
```

## Тесты

```powershell
.venv\Scripts\python -m unittest discover -s tests -v
```

27 тестов: правила жестов, стабилизатор, разбор хоткея и диспетчер действий.
Камера и MediaPipe не нужны — всё выполняется за миллисекунды.

## Настройка

Всё в `config.json`:

| Ключ | Смысл |
|---|---|
| `camera.index` | Номер камеры (0 — встроенная) |
| `camera.mirror` | Зеркалить картинку |
| `gesture.hold_ms` | Сколько держать жест до срабатывания |
| `gesture.cooldown_ms` | Пауза между срабатываниями |
| `gesture.extended_angle` | Порог «палец разогнут», градусы |
| `mute.backend` | `discord_hotkey` или `windows_mic` |
| `mute.hotkey` | Комбинация, которую слушает Discord |
| `actions` | Какой жест какое действие вызывает |
| `feedback.beep` | Звук при переключении микрофона |
| `feedback.show_preview` | Показывать окно |

Действия: `mute`, `unmute`, `toggle`, `play_pause`, `next_track`, `prev_track`.

Жесты: `point`, `closed_fist`, `open_palm`, `victory`, `thumb`, `thumb_left`,
`thumb_right`.

Пример: повесить паузу ещё и на открытую ладонь.

```json
"actions": {
  "point": "toggle",
  "closed_fist": "play_pause",
  "open_palm": "play_pause",
  "thumb_right": "next_track",
  "thumb_left": "prev_track"
}
```

## Почему Discord — через хоткей, а музыка — через медиа-клавиши

У Discord нет публичного способа выключить микрофон **своего** клиента: Bot API
умеет только серверный мут участника, локальный RPC устарел. Поэтому
используется официальная горячая клавиша Discord.

Для музыки, наоборот, есть стандартный механизм Windows — медиа-клавиши.
Яндекс Музыке не нужен ни API, ни токен: она уже умеет их слушать.

Подробнее про API и почему это так: [docs/discord-api.md](docs/discord-api.md).

## Если что-то не работает

**Жест виден, но Discord не реагирует** — не задан хоткей в Discord, Discord
закрыт, или Discord запущен от администратора, а программа нет.

**Музыка не реагирует** — ничего не играет (нет активной медиа-сессии), играет
другой плеер, или жест распознался не как `thumb_left` / `thumb_right`.
Посмотрите строку `gesture:` в превью.

**Кулак срабатывает случайно** — увеличьте `gesture.hold_ms` до 700–900.
Кулак — самое «бытовое» положение руки, поэтому он и страдает первым.

**Большой палец вбок не распознаётся** — держите остальные пальцы плотно
согнутыми, а большой отводите дальше в сторону: порог — 35% ширины кисти.
Если всё равно тяжело, уменьшите `THUMB_DEADZONE` в `gestures.py`.

**«Не удалось открыть камеру»** — камера занята (Zoom, OBS, браузер) или
запрещена в «Параметры → Конфиденциальность → Камера».

**Состояние MIC в превью не совпадает с Discord** — ожидаемо для
`discord_hotkey`: программа помнит только свои переключения.

**Кириллица в пути** — MediaPipe на Windows не открывает такие пути, поэтому
модель автоматически копируется в `C:\Users\Public\GestureMic\models`.

## Структура

```
gesture-mic/
├─ main.py          цикл: камера → жест → действие
├─ gestures.py      точки → имя жеста (чистые функции)
├─ stabilizer.py    удержание и пауза между срабатываниями
├─ actions.py       имя действия → вызов
├─ mute.py          backend'ы: Discord hotkey / Windows mic
├─ media.py         медиа-клавиши Windows
├─ win32_input.py   SendInput: нажатия клавиш
├─ overlay.py       скелет кисти и HUD
├─ config.json      настройки
├─ tests/           unittest, без камеры
├─ models/          сюда скачивается модель (в git не попадает)
└─ docs/            заметки про Discord API
```

## Ограничения

- Одна рука в кадре.
- Только статические позы, без движений.
- Медиа-клавиши управляют активным плеером, а не конкретно Яндекс Музыкой.
- Discord-хоткей не читает реальное состояние мута.
