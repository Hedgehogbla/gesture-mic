# Gesture Mic

Управление системным микрофоном жестами руки через вебкамеру.

Работает локально: кадры не покидают компьютер. Распознавание — по 21 точке кисти
(MediaPipe Hand Landmarker), классификация жестов — по углам сгиба пальцев.

## Жесты

| Жест | Действие по умолчанию |
|---|---|
| ✊ Кулак | Выключить микрофон |
| ✋ Открытая ладонь | Включить микрофон |
| ✌️ Victory (два пальца) | Переключить mute |

Жест нужно **удержать 0.5 секунды** — так случайное движение руки не выключит
микрофон посреди фразы. После срабатывания действует пауза 1.5 секунды.

Поза должна быть чёткой: расслабленная кисть с полусогнутыми пальцами не
считается кулаком и не выключает микрофон.

## Требования

- Windows 10/11
- Python 3.12 (MediaPipe не поддерживает 3.13+)
- Вебкамера
- Доступ к микрофону в параметрах Windows

## Установка

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

Модель `models/hand_landmarker.task` уже лежит в проекте. Если её нет, при запуске
она скачается автоматически.

## Запуск

```powershell
run.bat
```

Или напрямую:

```powershell
.venv\Scripts\python src\main.py
```

В окне превью: `Q` или `Esc` — выход. В консоли — `Ctrl+C`.

Полезные флаги:

```powershell
.venv\Scripts\python src\main.py --camera 1        # другая камера
.venv\Scripts\python src\main.py --no-window       # без окна превью
.venv\Scripts\python src\main.py --duration 10     # остановиться через 10 секунд
.venv\Scripts\python src\main.py --unmute          # включить микрофон и выйти
```

## Настройка

Всё лежит в `config.json`:

| Ключ | Смысл |
|---|---|
| `camera.index` | Номер камеры (0 — встроенная) |
| `camera.mirror` | Зеркалить картинку |
| `gesture.hold_ms` | Сколько держать жест до срабатывания |
| `gesture.cooldown_ms` | Пауза между срабатываниями |
| `gesture.extended_angle` | Порог «палец разогнут», градусы (больше — строже) |
| `gesture.curled_angle` | Порог «палец согнут», градусы (меньше — строже) |
| `actions` | Какой жест какое действие вызывает |
| `safety.skip_mute_while_recording` | Не выключать микрофон, пока другое приложение пишет |
| `safety.restore_mic_on_exit` | Вернуть состояние микрофона при выходе |
| `feedback.beep` | Звуковой сигнал при срабатывании |
| `feedback.show_preview` | Показывать окно |

Действия: `mute`, `unmute`, `toggle`. Жесты: `closed_fist`, `open_palm`, `victory`,
`point`, `thumb`. Несколько жестов могут вызывать одно действие, а лишние можно
просто убрать из `actions`.

## Как это работает

1. Кадр 640×480 с камеры.
2. MediaPipe Hand Landmarker находит 21 точку кисти.
3. Точки переводятся в пиксельные координаты `(x*w, y*h, z*w)` — иначе углы
   искажаются из-за разного масштаба осей кадра.
4. Для каждого пальца считается угол в суставе PIP: больше `extended_angle` —
   палец разогнут, меньше `curled_angle` — согнут. Углы между порогами считаются
   неоднозначными, поэтому расслабленная кисть не превращается в кулак.
5. Набор разогнутых пальцев превращается в жест. Кисть, обрезанная краем кадра,
   игнорируется.
6. Стабилизатор требует удержания `hold_ms` и не даёт сработать дважды за одно
   удержание.
7. `pycaw` через Windows Core Audio переключает mute у микрофона по умолчанию —
   это действует на все приложения сразу. Пока другое приложение активно пишет
   (звонок, голосовое, диктофон), выключение пропускается, чтобы не записать тишину.
8. При выходе микрофон возвращается в состояние, которое было на момент запуска
   (отключается через `safety.restore_mic_on_exit`).

## Если что-то не работает

**«Не удалось открыть камеру»** — камера занята другим приложением (Zoom, OBS,
браузер) или запрещена в «Параметры → Конфиденциальность → Камера».

**«Управление микрофоном отключено»** — не найден микрофон по умолчанию или
`pycaw` не смог получить доступ. Программа при этом продолжает работать в режиме
превью.

**Жесты срабатывают слишком легко** — увеличьте `gesture.hold_ms` до 700–900
или уменьшите `gesture.curled_angle` до 90: кулак придётся сжимать плотнее.

**Жесты не распознаются** — поднимите `gesture.extended_angle` не нужно; наоборот,
попробуйте снизить до 140, если пальцы кажутся «полусогнутыми» для алгоритма.
Также помогает свет спереди и рука целиком в кадре.

**Записал голосовое, а в нём тишина** — музыка при этом играет, потому что
воспроизведение и микрофон — разные устройства. Скорее всего, системный микрофон
был выключен (жестом или в Windows), и приложение записало тишину. Уже записанное
голосовое восстановить нельзя, но новые записи защищены: во время активной записи
жест выключения игнорируется, а при выходе состояние микрофона возвращается.
Проверить и включить микрофон можно командой:

```powershell
.venv\Scripts\python src\main.py --unmute
```

Если тишина повторяется, посмотрите «Параметры → Система → Звук → Ввод»: там же
видно, какой микрофон выбран и не выключен ли он. В окне превью состояние
показывается как `MIC ON` / `MIC OFF`.

**Нужно писать с микрофона наушников** — подключите наушники в Windows, затем
переключите микрофон по умолчанию. Telegram, Discord и другие приложения берут
устройство ввода из Windows, отдельная настройка в них не нужна:

```powershell
.venv\Scripts\python tools\use_headset_mic.py
.venv\Scripts\python tools\use_headset_mic.py --list   # что вообще подключено
```

Скрипт сам находит активный микрофон гарнитуры (`Hands-Free`, `Headset`,
`Головной телефон`) и ставит его устройством ввода для всех ролей Windows.

**Кириллица в пути** — MediaPipe на Windows не открывает такие пути, поэтому
модель автоматически копируется в `C:\Users\Public\GestureMic\models`.

## Ограничения текущей версии

- Одна рука в кадре.
- Только статические позы, без движений (взмахов, свайпов).
- Управляется системный микрофон по умолчанию, а не отдельное приложение.
- Нет фонового режима и автозапуска — окно превью нужно держать открытым.

## Что можно добавить дальше

- Свои жесты: сбор 100–200 примеров и маленький классификатор на landmarks.
- Действия помимо микрофона: камера, громкость, медиа-пауза, запуск программ.
- Режим трея без окна превью.
- Автозапуск вместе с Windows.
